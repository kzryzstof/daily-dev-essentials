# Claude MCP Servers Configuration

Place the `mcpServers` block inside `~/.claude.json` to register MCP servers for Claude Desktop / Claude CLI.

## Servers

| Server | Transport | Description |
|--------|-----------|-------------|
| 🐙 **github** | `http` | GitHub repos, PRs, issues, Actions, and secret scanning via the GitHub Copilot remote MCP endpoint. Requires a `GITHUB_TOKEN` env var. |
| 📓 **notes** | `stdio` | Personal notes workspace — reads and writes Markdown files under the local Notes vault via a local shell script. |
| 🎭 **playwright** | `stdio` | Browser automation and web scraping via accessibility snapshots. Useful for fetching live documentation or interacting with web UIs. |
| 🗂️ **jira-confluence** | `stdio` | Jira issue tracking and Confluence wiki access for the SwiftConnect workspace via the Anthropic Atlassian MCP package. Requires a `JIRA_API_TOKEN` env var. |

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer ${GITHUB_TOKEN}"
      }
    },
    "notes": {
      "type": "stdio",
      "command": "/Users/christophe/Notes/BoK/prompts/scripts/notes-mcp.sh",
      "args": []
    },
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    },
    "jira-confluence": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-atlassian"],
      "env": {
        "CONFLUENCE_URL": "https://swiftconnect.atlassian.net",
        "CONFLUENCE_USERNAME": "",
        "CONFLUENCE_API_TOKEN": "${JIRA_API_TOKEN}",
        "JIRA_URL": "https://swiftconnect.atlassian.net",
        "JIRA_USERNAME": "",
        "JIRA_API_TOKEN": "${JIRA_API_TOKEN}"
      }
    }
  }
}
```
