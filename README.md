# Daily Dev Essentials

A collection of reusable code, development configuration, and prompt skills for everyday
engineering work.

## Repository structure

| Path | Contents |
|---|---|
| [`azure/`](azure/) | Azure utilities, including helpers for constructing dependency-injection hosts in Azure Functions tests. |
| [`csharp/`](csharp/) | C# utilities, including test assertion and mock-verification helpers. |
| [`ide/`](ide/) | IDE configuration and documentation for JetBrains Rider. |
| [`prompts/`](prompts/README.md) | Reusable prompt skills, shared coding conventions, and the local skill-update script. |

## Prompt skills

See the [`prompts` README](prompts/README.md) for the skill inventory, workflow diagram, shared
conventions, and local update instructions.
